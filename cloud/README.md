# LYA CLOUD — access her from anywhere, even with your laptop OFF

## Short answer to "do we still need Tailscale?"

| What you want | Solution | Tailscale needed? |
|---|---|---|
| Laptop ON, access from any WiFi/mobile data | Tailscale tunnel | ✅ Yes |
| Laptop OFF, LYA still answers 24/7 | **Cloud edition (this guide)** | ❌ No — she lives on the internet |

Once the cloud edition is deployed, Tailscale becomes optional — the cloud LYA
is reachable from anywhere through her normal https address.
Many people keep BOTH: cloud LYA as the always-on version, laptop as her
"home body" with voice, face, and device control.

## The two-layer plan

### Layer 1 — Laptop ON, any network: Tailscale (free)
1. Install Tailscale on your laptop AND iPhone (https://tailscale.com — free for personal use)
2. Sign in with the same account on both
3. On iPhone, open LYA at `http://<laptop-tailscale-ip>:5000` (Tailscale app shows your laptop's IP, looks like `100.x.x.x`)
4. Works from office, travel, anywhere — encrypted WireGuard tunnel, no port forwarding
5. Start her with `python web_server.py` as usual

### Layer 2 — Laptop OFF: free cloud hosting (no subscription ever)
Her brain runs on Render's free tier; memories live in Supabase's free Postgres.
Both free forever. Nothing installs on your phone.

## One-time setup (15 minutes)

### 1. Create the memory database (Supabase — free)
- Sign up at https://supabase.com (free, no card)
- New project → after it's ready, go to **SQL Editor** and run:

```sql
create table memories (
  id bigint generated by default as identity primary key,
  kind text,
  ekey text,
  evalue text,
  importance real default 1,
  hits int default 0,
  created timestamp default now()
);
```

- Then: **Project Settings → API** — copy the `Project URL` and `anon public key`

### 2. Deploy her brain (Render — free)
- Sign up at https://render.com (free, no card)
- New → **Web Service** → connect this project (or use "Deploy from GitHub")
- Settings:
  - **Build command:** `pip install cryptography`
  - **Start command:** `python cloud/lya_cloud.py`
- Add the environment variables (Render dashboard → Environment):
  - `LYA_PASSPHRASE` = invent a strong passphrase — **this encrypts every memory; if you lose it, memories are unreadable. Save it somewhere safe!**
  - `LYA_PHONE_TOKEN` = your existing token (or a new one)
  - `GROQ_API_KEY` = your Groq key
  - `SUPABASE_URL` = your Supabase project URL
  - `SUPABASE_KEY` = your Supabase anon key

### 3. iPhone
- Open your Render URL (like `https://lya.onrender.com`) in Safari
- Share → Add to Home Screen → done. **Works from anywhere, laptop off.**

## Security (multi-level, even in the cloud)
| Level | Guard |
|---|---|
| 1 | Phone token — wrong token = 403 |
| 2 | Every memory AES-256 encrypted with YOUR passphrase before it ever leaves the server |
| 3 | Supabase sees only ciphertext; Render sees only ciphertext |
| 4 | Lose the passphrase = memories unreadable, even by us |

## Free-tier honesty
- Render free: spins down after 15 min idle → her first reply after a pause takes ~30s to wake ("cold start"), then fast. Battery/storage on your phone: unaffected.
- Supabase free: 500MB database — years of personal memory.
